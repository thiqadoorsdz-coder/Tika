الربط مع Google Sheets

يرسل البرنامج نسخة من الطلبيات والقطع والدفعات والمصاريف والمخزون إلى شيت عندك (اتجاه واحد: من البرنامج إلى الشيت).

كود Apps Script وطريقة التركيب
  1. افتح Google Sheets وأنشئ شيتاً جديداً ← Extensions ← Apps Script.
  2. امسح ما فيه والصق الكود أدناه، وغيّر الرمز السري.
  3. Deploy ← New deployment ← النوع Web app ← Execute as: Me ← Who has access: Anyone ← Deploy، ووافق على الصلاحيات.
  4. انسخ رابط Web app (ينتهي بـ /exec) والصقه أعلاه مع نفس الرمز السري.
